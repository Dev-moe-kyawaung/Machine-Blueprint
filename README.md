# Mecha Engineer Blueprint Portfolio

A premium Next.js portfolio with mechanical blueprint aesthetics, featuring line-draw animations, schematic transitions, gear rotations, and exploded-view project reveals.

## Features

- 🎨 **Blueprint Theme**: Mechanical engineering-inspired design with grid patterns and technical aesthetics
- ✏️ **Line-Draw Animations**: SVG paths that draw themselves on scroll
- ⚙️ **Animated Gears**: Rotating gear systems in backgrounds
- 💥 **Exploded Views**: Interactive project architecture visualization
- 🤖 **AI Assistant**: Chat interface for portfolio navigation and blueprint generation
- 📱 **Fully Responsive**: Optimized for all devices
- 🚀 **Performance**: Optimized with Next.js and modern best practices

## Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP
- **3D**: Three.js, React Three Fiber
- **Icons**: Lucide React
